## Features
- **Glass‑morphism UI** – translucent panels with `backdrop-filter: blur(12px)`.
- **Responsive layout** – adapts at 390 px, 768 px, 1024 px, 1440 px.
- **Interactive timeline** – switches between Chaturanga, Shatranj, Modern Chess.
- **3‑D model viewer** – lazy‑loaded `<model‑viewer>` showing a chess board.
- **Game inspirations grid** – static cards that can be swapped out for dynamic content later.

## Customisation
- Swap the hero image, colours (`--color-bg`, `--color‑accent`) or fonts in `style.css`.
- Extend the demo panel with a real chess engine or WebGL board.
- Add more sections or a blog‑style archive by copying the existing section pattern.
